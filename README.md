# Dayo Travel and Tours

Static site: `index.html` + `img/`. No build step.

## Edit contact links
Open `index.html`, find `const CONFIG` (near the bottom, inside `<script>`), and change the phone, email, Instagram and Facebook values.
Set `facebook` to your real Page URL.

## Deploy on Vercel
See the steps in the chat, or: `npm i -g vercel && vercel --prod` from this folder.
